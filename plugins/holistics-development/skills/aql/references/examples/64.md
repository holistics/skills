## Dataset fields
```yaml
dimensions:
- field: id
  model: order_items
- field: amount
  model: order_items
- field: id
  model: products
- field: name
  model: products
measures: []
params:
- field: top_n_param
  model: products
  type: number
```

## AQL
```aql
metric revenue = order_items | sum(order_items.amount);
metric top_n_products = top(first(products.top_n_param), products.name, by: revenue, logic: 'dense');

explore {
  dimensions {
    product_name: products.name,
  }
  measures {
    revenue: revenue,
  }
  filters {
    products.name in top_n_products,
  }
  sorts {
    revenue DESC,
    product_name ASC,
  }
}
```

## Learning points
* `first()` turns a param into a **constant**, so it can be passed where a constant argument is expected
