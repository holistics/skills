## Dataset fields
```yaml
dimensions:
- field: id
  model: orders
- field: created_at
  model: orders
- field: id
  model: order_items
- field: amount
  model: order_items
- field: name
  model: countries
measures: []
params:
- field: date_param
  model: orders
  type: datetime
```

## AQL
```aql
metric revenue = order_items | sum(order_items.amount);

explore {
  dimensions {
    country: countries.name,
  }
  measures {
    revenue: revenue,
  }
	filters {
    orders.date matches @(last month),
  }
  params {
    orders.date_param matches @(last month),
  }
  sorts {
    country ASC,
  }
}
```

## Learning points
* The user never mentions the param, but the model has a date param for the same period: set the time range on both the param and dimension
* Date/datetime params take the same time expressions as explore filters
