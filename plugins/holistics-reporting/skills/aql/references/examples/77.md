params:
- field: gender_param

## Bad AQL
```aql
metric revenue = order_items | sum(order_items.amount);
metric revenue_of_selected_gender = revenue | where(orders.gender == orders.gender_param);

explore {
  dimensions {
    gender_param: orders.gender_param,
  }
  measures {
    revenue_of_selected_gender: revenue_of_selected_gender,
  }
}
```

## Why it's bad
* A param is a **list** of the values set for it, so it CANNOT be compared with `==`. Use `orders.gender in orders.gender_param`, or `orders.gender == (orders.gender_param | first())`
* A param CANNOT be put in `explore.dimensions` either. To show the selected value, aggregate the corresponding dimension instead
