## Dataset fields
```yaml
dimensions:
- field: id
  model: orders
- field: created_at
  model: orders
- field: gender
  model: orders
- field: id
  model: order_items
- field: amount
  model: order_items
measures: []
params:
- field: gender_param
  model: orders
  type: text
```

## AQL
```aql
metric revenue = order_items | sum(order_items.amount);
metric revenue_of_selected_genders = revenue | where(orders.gender in orders.gender_param);

explore {
  dimensions {
    month: orders.created_at | month(),
  }
  measures {
    revenue_of_selected_genders: revenue_of_selected_genders,
  }
  sorts {
    month ASC,
  }
}
```

## Learning points
* `where()` can compare a dimension against a param with `in`
* For a single value, compare against `orders.gender_param | first()` instead
