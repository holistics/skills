## Dataset fields
```yaml
dimensions:
- field: id
  model: orders
- field: created_at
  model: orders
- field: id
  model: order_items
- field: amount
  model: order_items
- field: id
  model: products
- field: category
  model: products
measures: []
params:
- field: category_param
  model: products
  type: text
```

## Bad AQL
```aql
metric revenue = order_items | sum(order_items.amount);

explore {
  dimensions {
    month: orders.created_at | month(),
  }
  measures {
    revenue: revenue,
  }
  filters {
    products.category_param in ['Books', 'Toys'],
  }
  sorts {
    month ASC,
  }
}
```

## Why it's bad
* Param values can ONLY be set in `explore.params`. Setting one in `explore.filters` fails with `Unsupported operator ... for type Table`
