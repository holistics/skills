## Dataset fields
```yaml
dimensions:
- field: id
  model: orders
- field: id
  model: order_items
- field: amount
  model: order_items
- field: name
  model: countries
measures: []
params:
- field: metric_selector
  model: param_model
  type: text
```

## AQL
```aql
metric revenue = order_items | sum(order_items.amount);
metric order_count = orders | count(orders.id);
metric selected_metric = case(when: 'Revenue' in param_model.metric_selector, then: revenue, else: order_count);

explore {
  dimensions {
    country: countries.name,
  }
  measures {
    selected_metric: selected_metric,
  }
  sorts {
    country ASC,
  }
}
```

## Learning points
* A param holds a **list** of the values set for it, so test the selection with `in`
