## Dataset fields
```yaml
dimensions:
- field: id
  model: orders
- field: created_at
  model: orders
- field: id
  model: order_items
- field: amount
  model: order_items
- field: id
  model: products
- field: category
  model: products
measures: []
params:
- field: category_param
  model: products
  type: text
```

## AQL
```aql
metric revenue = order_items | sum(order_items.amount);

explore {
  dimensions {
    month: orders.created_at | month(),
  }
  measures {
    revenue: revenue,
  }
  params {
    products.category_param in ['Books', 'Toys'],
  }
  sorts {
    month ASC,
  }
}
```

## Learning points
* Params are set in `explore.params`, never in `explore.filters`
* `in` takes a list of values; single-value operators like `is` take one value
